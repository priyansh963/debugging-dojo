# Playbook

Patterns I've learned from real bugs in this repo. A pattern only goes here after I've
actually hit it, with a link to the drill where it happened.

## General method
1. Reproduce it reliably.
2. Cut the system in half: is the problem before or after this point?
3. One hypothesis at a time. Change one thing at a time.
4. Read the last stack-trace line that points into *my* code.
